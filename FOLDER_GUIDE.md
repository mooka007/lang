# Project Directories

- **front/**: Next.js frontend, UI components, layout, styling, and UX work.
- **server/**: Express.js API and LangChain.js RAG pipeline.
- **server/pdfs/**: Source PDF, Markdown, or text documents for testing and development.
- **server/uploads/**: User-uploaded files during app usage.
- **server/data/**: Processed data, embeddings, vector-store files, and local server logs.
- **scripts/**: Utility scripts, including the sample PDF generator.

The main starter sample lives in `server/pdfs/company-x-employee-knowledge-base.md` and `server/pdfs/company-x-employee-knowledge-base.pdf`.
